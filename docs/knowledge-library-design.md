# 知识库与教案自动组合设计

## 当前实现

- 蒸馏结果以知识卡片形式保存在浏览器 localStorage。
- 卡片保留来源类型、来源名称、章节/页码/时间戳、生成时间、蒸馏 Markdown 和标签。
- 教案页根据主题、学段、班级背景做轻量关键词匹配，优先选择最相关的卡片；无匹配时不以无关卡片补位，并在页面上展示选择结果。
- 用户可以取消勾选不适合本次教案的卡片，模型会收到选中的来源信息和知识摘要。
- 知识库页面允许查看与删除卡片。

## 当前边界

这是浏览器本地知识库，不是多用户云端数据库；资料不会跨设备同步，也不自动共享给其他教师。自动匹配是关键词级候选排序，不等于语义检索或事实核验。PDF 文本层可以提取，纯扫描图片 PDF 需要 OCR，当前不承诺自动识别扫描页。

## 后续演进

1. 增加用户身份与数据库持久化。
2. 将 PDF 解析和大文件切片移到服务端作业队列。
3. 增加向量检索、来源片段引用与匹配理由。
4. 加入教案版本、导出 DOCX/PDF 和教师审核流程。
5. 依据授权和使用范围管理课程资料，避免把完整受版权保护材料当作可公开共享内容。

## 首批选章语料接入（2026-10-26）

- `data/psychology-corpus/corpus.json` 登记10本选章核读来源、9类主题、15张知识卡，以及6个未返回附件的未知槽位。
- `lib/psychology-corpus-schema.ts` 定义可校验字段并检查跨记录关系：卡片来源存在、页码属于已核读正文、主题和学段有效、数量一致。JSON Schema保存在同目录。
- 知识库页面提供“导入首批15张知识卡”。只新增缺失ID，不覆盖已有同ID内容；容量不足时提示整理，不静默丢弃旧卡。
- `distillation` 是旧卡片格式的可选扩展；旧备份仍可导入，新备份保留结构化来源、学段、活动与边界。
- 主题推荐按首批卡的学段过滤；学段词不会单独造成命中。普通旧卡因没有结构化学段仍作为待教师判断的候选。推荐是关键词筛选，不等于事实核验。
- 教案接口收到首批卡ID后从服务器取回对应原始知识卡，避免客户端删改来源或限制。未知ID及不适龄卡被拒绝；教师指导用途和物理页码说明进入生成提示。
- 未改变模型、未训练权重；书籍段落核读与活动效果验证是不同状态。没有发布原PDF或提取全文。

详见 [蒸馏记录](psychology-distillation-corpus.md)。运行 `npm run test:corpus` 校验结构、引用与筛选行为，`npm run typecheck` 和 `npm run build` 校验应用接入。
