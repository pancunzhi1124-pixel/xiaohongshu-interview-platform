# 知识库与教案自动组合设计

## 当前实现

- 蒸馏结果以知识卡片形式保存在浏览器 localStorage。
- 卡片保留来源类型、来源名称、章节/页码/时间戳、生成时间、蒸馏 Markdown 和标签。
- 教案页根据主题、学段、班级背景做轻量关键词匹配，优先选择最相关的卡片；无匹配时不以无关卡片补位，并在页面上展示选择结果。
- 用户可以取消勾选不适合本次教案的卡片，模型会收到选中的来源信息和知识摘要。
- 知识库页面允许查看与删除卡片。

## 当前边界

这是浏览器本地知识库，不是多用户云端数据库；资料不会跨设备同步，也不自动共享给其他教师。自动匹配是关键词级候选排序，不等于语义检索或事实核验。PDF 文本层可以提取，纯扫描图片 PDF 需要 OCR，当前不承诺自动识别扫描页。

## 后续演进

1. 增加用户身份与数据库持久化。
2. 将 PDF 解析和大文件切片移到服务端作业队列。
3. 增加向量检索、来源片段引用与匹配理由。
4. 加入教案版本、导出 DOCX/PDF 和教师审核流程。
5. 依据授权和使用范围管理课程资料，避免把完整受版权保护材料当作可公开共享内容。

## 全书阅读语料接入（2026-10-26，v2）

- `data/psychology-corpus/corpus.json`：18本来源、12类主题、45张知识卡；17PDF共11846物理页，1EPUB按正文文件/段号定位。
- 每本有`reading-logs/`逐章记录及指纹，总审计与历史待办澄清见`reading-audit.json`；不是仅修改状态字段。
- Zod/JSON Schema及跨记录校验检查正文范围、EPUB定位和数量，测试另核实际记录文件、摘要和指纹。
- 知识库导入本轮版本卡，保留旧卡与自有卡；同ID不覆盖，容量不足原样拒绝，旧结构化备份兼容。
- 教案推荐先匹配主题再按学段筛选；服务端从本轮官方ID恢复来源内容，EPUB定位与教师指导边界一并传递。
- 原创活动尚未试教；没有模型权重训练、当前医学/法律标准全量复核或真实模型效果验证。
