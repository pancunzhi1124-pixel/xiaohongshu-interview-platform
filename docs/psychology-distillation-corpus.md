# 班会知识蒸馏首批交付

本轮实际读取了10本可访问PDF的书目信息、目录和相关正文片段，形成15张中文知识卡。原消息记录16个附件；其余6个附件没有返回，书名未知。没有一本标为全文已读。全文件文本提取只是检索准备，不能算作全文核读。本文所谓蒸馏是知识提炼与教学转化，没有训练模型或更新模型权重。

- 导出包中的 `source-register.md`：版本、正文阅读范围、未处理范围和文件指纹。
- 导出包中的 `knowledge-cards.md`：便于教师阅读的15张知识卡。
- `corpus.json`：主题分类、来源登记、逐卡方法/学段/活动/边界/页码的结构化语料。
- `knowledge-library-import.json`：兼容现有知识库页面的导入数组；在“我的知识库”导入备份即可使用。
- `corpus.schema.json`：结构契约；源码另以Zod及跨记录检查验证。
- `validation-report.md`：实际执行的验证和GitHub接入结果。

## 使用与组合

先指定班会主题、学段和一个可观察目标，再选择2—4张直接相关的学生活动卡；教师指导卡用于审查安全、评价及学段支架，不能直接当作学生治疗活动。推荐只提供候选，教师仍需确认。小学低段与高段分开记录；页面选择“小学”时会覆盖两组，教师应进一步核对具体年级。

例如“同伴合作/初中”：K12信息互补活动为主，K06审查贡献与轮换，K01审查标签语言，K14提供教师隐私与退出权检查。40分钟可分为情境引入5、独立观察5、拼图合作12、技能反馈8、迁移计划5、匿名评价5；时间表为本轮原创示例，未实地试教，不是原书教案。每张采用卡须在教案来源表标出卡ID、版本、PDF物理页和活动用途。

“睡眠与学习/高中”：K04用于分析安排，K05用于分散练习计划，K03用于校准时间。活动不得通过实际熬夜来演示，也不承诺固定提分比例。“创伤复原”不应直接作为全班治疗主题；K07、K08供教师审查参与选择、安全和支持路径。

## 证据和版权

正文摘要仅概括核读段落。课程、教师个人经验、本轮原创活动与书籍表述必须分开。对原始研究、效应大小、当下诊断标准和具体学生干预效果未做系统证据评审；书内提到某研究不等于本轮独立核验了它。学段、时间和活动步骤均为教学判断。未发布PDF、整章文本、扫描页或提取全文；文件指纹用于识别同一来源，不能证明授权。

PDF物理页从封面开始计数。`printedPages: null`表示未建立稳定的纸书页码映射，不应由模型补全。重排电子书尤其不能把页脚数字当成同版纸书页码。

教师安全边界也参考了 [NCTSN学校资源](https://www.nctsn.org/trauma-informed-care/creating-trauma-informed-systems/schools)：学校提供安全支持、调整课堂并按需转介。此网页是补充，不计入上传书籍。具体保护、记录和危机处理须依学校既定流程；班会不作诊断、治疗或危机干预。
