# 主题班会教案质量检查表

提交教案前逐项检查。若任一安全项不通过，必须先修改。

## A. 学情与目标

- [ ] 写清楚年级、时长与班级情境；事实和假设没有混淆。
- [ ] 主题对应真实的学生发展需要，不只是成人想讲的道理。
- [ ] 目标可观察，避免只写“提高意识”“增强能力”。
- [ ] 目标数量合理，并与活动、评价一一对应。

## B. 知识与来源

- [ ] 每条核心知识有来源，或明确说明是通用教学建议。
- [ ] 没有虚构作者观点、老师原话、页码、时间戳或研究结果。
- [ ] 理论名称不是装饰；活动确实体现相应机制。
- [ ] 写明适用边界与需要教师判断的部分。
- [ ] 没有复制过长的受版权保护原文。

## C. 活动与课堂可行性

- [ ] 学生有真实参与，而非全程听老师讲。
- [ ] 每个环节都有教师动作、学生活动和设计意图。
- [ ] 分钟数相加等于总时长。
- [ ] 材料、空间、分组方式符合真实课堂条件。
- [ ] 教师话术自然，包含必要的转场与追问。
- [ ] 活动结束后有总结、练习或迁移，而非突然收尾。
- [ ] 有当堂学习证据和课后延伸。

## D. 学生安全与包容性

- [ ] 不要求学生公开披露创伤、家庭隐私或心理困扰。
- [ ] 不羞辱、不排名、不强迫表态、不将沉默视为问题。
- [ ] 敏感活动提供旁观、跳过或替代任务。
- [ ] 不给学生贴心理诊断标签。
- [ ] 涉及高风险情况时，有校内求助或专业支持路径。
- [ ] 示例使用虚构情境，不泄露可识别个案信息。

## E. 最终可实施性

- [ ] 班主任看完后知道何时说什么、让学生做什么。
- [ ] 有预估的学生反应及相应的教师应对方式。
- [ ] 对可能超时、冷场、争论升级或学生不愿参与有备选方案。
- [ ] 教案语气尊重学生，避免空泛口号。
