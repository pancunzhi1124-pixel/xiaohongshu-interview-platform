# 心理学书籍与教师课程的知识蒸馏方法

## 目标

把长篇资料转成能够检索、组合、追溯并用于主题班会设计的“知识卡”。蒸馏的目标是保留可迁移的概念与方法，而不是复刻原书或完整课程。

## 处理步骤

### 1. 建立来源记录

记录以下元数据：

- 来源类型：心理学书籍、教师课程、讲座、培训或其他。
- 标题、作者/授课者、版本/课程日期（若已知）。
- 输入材料范围：哪些章节、笔记或课程片段。
- 精确定位：页码、章节、视频时间戳；未提供则如实标注。
- 使用权限与保密注意事项。

### 2. 区分四种信息

每个结论标记其性质：

- **来源明确陈述**：输入材料中可以找到直接依据。
- **忠实转述**：用自己的话表达来源观点。
- **教学转化**：为了适配班会，把观点转成活动、提问或教师话术。
- **待核实推断**：输入材料不足，不能确认是作者/老师的观点。

不要将后两类写成来源原话。

### 3. 生成标准知识卡

建议结构：

1. 一句话主旨。
2. 3—8 个核心概念：概念名称、通俗解释、适用情境。
3. 方法卡：目标、前提、步骤、所需材料、适用年级、失败信号、替代做法。
4. 班会转化：学生需要、活动机制、教师引导语、可观察学习证据。
5. 适用边界：哪些情境不适合、哪些学生可能需要替代参与、何时需专业支持。
6. 来源依据：对应章节/页码/时间戳或“材料未提供精确定位”。
7. 可信度与待核实项。

### 4. 从理论转成课堂活动

使用以下映射问题：

- 学生需要理解什么？
- 学生需要亲自体验、练习或讨论什么？
- 哪个活动环节体现了这个理论，而不是只在教案里提到理论名称？
- 教师可以观察到什么证据？
- 学生怎样把方法迁移到下周的真实生活？
- 这个活动是否会造成暴露、羞辱、标签化或同伴压力？

### 5. 质量标准

- **忠实**：不捏造来源观点、引用、研究结果或页码。
- **精炼**：每个概念都能回答“这对班会有什么用”。
- **可操作**：方法有具体步骤，而非只写“增强共情”“提升自信”。
- **可迁移**：能适配不同年级，但会明确需要调整的部分。
- **有边界**：说明不能解决什么问题，避免将班会等同于治疗。
- **可组合**：每张卡尽量只表达一个核心方法或机制。
- **有追溯性**：保留来源定位和推断说明。

## 建议的知识卡文件名

- 心理学书籍：knowledge/books/<主题或书名缩写>.md
- 教师课程：knowledge/courses/<课程主题或老师简称>.md

保存前人工审核，避免保存未经核实的 AI 推断或敏感个案信息。
