# 根据教案生成课堂课件

用户要求配套PPT时使用。课件用于支持课堂活动，不能代替教师响应或学生体验。先读取指定教案、主技能及年级学期适配规则，保留教案目标、资料追溯和参与选择。

## 检查输入与教案

- 明确具体年级、学期或未定状态、课时、课堂用途及要求的输出格式。学校模板、比例、设备、联网条件仅在影响制作时确认；未指定比例可用16比9并说明假设。
- 识别已有教案的情境、语言、目标和活动是否适合学生。必要的内容修正记录原因，并同步到逐页脚本；若用户要求保留原教案，先列出实质冲突并处理，不悄悄改写核心目标或时长。
- 不把教案的教学目标、准备清单、理论说明、风险预案、家长信和资料表全部搬到学生画面。按课堂需要分别放入教师备注或已有配套材料。

## 页数与时间

- 本项目配套PPT默认不少于20页、不多于30页，优先按24页规划。用户后续明确指定其他范围时采用新要求。范围是交付规格，不是证明课堂有效的标准。
- 以最终文件所有幻灯片的实际数量计数，包括封面、结束页、附录和隐藏页。教师备注不是幻灯片，不计页数；不靠隐藏页、重复结尾、无用途过渡或无关知识凑数。
- 每页有独立教学用途；增加页面可用于分步呈现情境、明确活动指令、示范或迁移，但不强制每个环节固定页数。不通过增加知识目标或延长课程凑页。
- 页数不决定停留时间。快速故事页可以连续展示，排练时可以停留在同一任务页。全部页面预计停留时间的总和与课时一致，包含讨论、材料转换及反馈；分组计时时不得重复累加父环节与子页面时间。

## 制作前形成逐页脚本

为每页记录以下内容，可用表格或结构化数据，不强制技术格式：

| 字段 | 要求 |
| --- | --- |
| 页码与对应环节 | 能追溯到指定教案的活动；核心教学目标都有对应页面 |
| 本页教学用途 | 说明本页为何需要存在，不能只写标题 |
| 学生可见内容 | 适龄的文字、图示和选项，不含备课长段落 |
| 学生任务 | 具体动作；故事或示范页也可记录“听或观察”，不强行每页互动 |
| 教师备注 | 引导语、实施步骤、可能回应及必要的支持、退出与替代方式 |
| 时间与翻页条件 | 时间计入课时，说明何时完成或转入下一页，允许教师响应实际情况 |
| 资料定位 | 用到知识卡时记录卡片ID、语料版本、书名及真实页码或EPUB定位；原创活动标明改编，纯过渡页无需虚构引用 |

脚本完成后检查目标、活动、评价是否一致，再进入排版。用户直接要求成品时自主完成该检查，不把批准逐页脚本设为固定前置审批。

## 学生画面与教师备注

- 一页聚焦一个当前任务或相互紧密相关的信息。活动页写清当前要做什么和可用的参与方式，教师说明可分步口述。
- 一年级以故事、图示、示范和短指令为主，不依赖独立阅读。上学期优先充分示范、单步任务和少量选项；下学期根据实际理解与经验增加选择或迁移，保留所需支持。
- 不机械设定统一字数、字号或“每页必须有图片”。以教室后排能看清、教师能口述、儿童能执行为判断；不把长文缩小来塞满页面。需要拼音时按实际识字与教学方式选择，不自动给所有文字加拼音。
- 教师备注提供足以实施的具体信息，与该页画面及时间一致；相关环节应能找到隐私、旁观、退出、替代与接续支持安排，避免仅写笼统口号。
- 学生画面不呈现诊断分类、旧临床风险比例、心理筛查评分或让学生自证情绪变化。来源和证据限制放在教师备注或配套来源表，不能用“科学证明”替代实际证据。

## 视觉与文件制作

- 默认交付可编辑PPTX，或按用户明确指定的其他课件格式交付。关键文字、活动选项和结构保留可编辑性；插画可以是图片，不把所有幻灯片压成整页图片。
- 插图须帮助理解情境、动作或选择。同一故事人物、图示含义与按钮标识保持一致；允许无图页面，不强制逐页生图，不使用无关装饰或复杂背景增加理解负担。
- 核心教学在无动画、断网或无法播放音视频时仍可开展。可选媒体注明出处与替代方式，不自动购买素材、发布课件或上传学校资料。
- 根据当前可用的演示文稿工具或技能完成文件制作与渲染，不将本技能绑定到特定付费服务。若工具无法写入教师备注，保留逐页对应的教师讲稿并如实说明限制，不声称文件已有备注。

## 检查与交付

1. 核对最终实际页数在要求范围内，各页有用途，核心目标都有对应活动和观察证据。
2. 核对逐页或环节时间总和，保留真实的学生操作时间，不按页数平均分配课时。
3. 核对具体年级、学期、课堂用语和读写要求，教师备注与学生画面一致。
4. 核对来源位置、原创改编标记和限制；无关页面不堆砌引用，未核实处不补造。
5. 检查文字与选项可编辑，教师备注实际存在；渲染并逐页检查溢出、遮挡、缺字、对比与图示含义，修正后重新检查受影响页面。
6. 交付实际课件及用户要求的配套材料。逐页脚本不能冒充PPT成品；未完成渲染或缺少功能时准确说明，不声称已经完成检查。

文件检查与真实试教分别记录。试讲重点观察儿童是否理解任务、教师需要临时补充多少解释、活动是否来得及完成、支持选择是否实际可用；不因页数达标或视觉整齐就认定教学有效。
