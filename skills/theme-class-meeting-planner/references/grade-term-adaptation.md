# 年级与学期适配

用于设计教案及其配套课件。学期提供可能的生活情境和学习经验线索，实际班情决定本课目标、任务难度与支持。以下示例是教学设计建议，不是各学期儿童能力的统一标准。

## 明确年级与学期

- **年级**：使用具体年级，不能仅用“小学低段”代替一年级与二年级的差异。
- **学期**：上学期、下学期或未定；必要时了解入学初期、学期中或学期末，以及是否新组班、转学、长期缺课。

不要从当前月份、目录名或所读书籍文件名推断学期。缺失信息实质影响活动时，先问一个必要问题；适合通用设计时，标明学期未定，选较低的文字与步骤要求，给出替换点，不自动生成两份完整教案。

## 调整的依据与输出

优先核对与本课相关的少量信息：能否理解当前指令、是否熟悉参与规则、能否用说话/指图/书写表达、是否做过相近活动、有哪些现实困难和支持资源。没有观察资料时写为待核实假设。

在教案“班级需求和设计依据”中简短写明：

1. 本学期的情境与已有经验，区分教师提供的信息和设计假设。
2. 本课优先目标及理由；不为区分上下学期而硬换核心目标。
3. 案例、指令长度、选项数量、活动形式、支持与迁移方式的具体调整。
4. 判断本次是否适合继续推进的可观察证据；允许回到示范、缩小任务或保留支持。

年级和学期仅是初始判断。不能假设下学期儿童已经熟练阅读、可以长时间独立工作、应该少求助，或把仍需支持解释为落后。进阶也可以是同一方法用于新情境、间隔后再次练习或由儿童自主选择支持。

## 一年级同主题的上下学期示例

以“任务前有点紧张”为例，两学期都可保留“辨认需要、选择一小步、适当求助”的核心目标。

| 维度 | 上学期可优先考虑 | 下学期在已有观察支持时可尝试 |
| --- | --- | --- |
| 班级情境 | 进入校园、认识老师、首次参与展示或集体任务 | 熟悉课堂中的练习、合作或作品展示；返校与新任务仍可需要重新适应 |
| 本课侧重点 | 找到可信成人，知道可以求助与选择参与方式 | 在熟悉方法之间作选择，迁移到另一个普通任务 |
| 指令与材料 | 教师口述并示范，一次一个动作、两个主要选项，图卡可指选 | 保留口述与图示；能理解时再增加简短理由或两个相连动作，不以阅读作参与前提 |
| 体验活动 | 替虚构人物指图，跟随教师练一句求助语 | 自选图卡，两人短回合排练；仍可独立、旁观或由成人代说 |
| 反思问题 | “它需要谁帮忙？”“现在可以先做什么？” | “这个办法什么时候方便用？”“不方便时可以怎样改？” |
| 迁移行动 | 在熟悉成人提示下试一次 | 自愿选择一个生活提示，尝试后修改；不强制打卡或取消成人提示 |
| 评价证据 | 能指选支持方式或表达需要 | 在新情境中选择可行动作，并在需要时提出支持；不要求情绪立即下降 |

这些差别不能只改标题。若下学期班级仍在建立参与规则，应继续使用上表左侧的支持；若上学期已有相应经验，也可以适当尝试迁移。

## 其他年级的使用原则

- 新入学、升学或新组班的上学期，可优先了解归属感、规则理解和求助渠道；不能把每个上学期都写成新生入学。
- 经验较稳定时，可围绕同一目标加入协商、选择理由或迁移；是否适合由课堂观察决定，不按上下学期自动增加文字、讨论时长或难度。
- 同伴合作、挫折应对、信息判断等主题可跨学期反复出现。先了解上次做过什么及仍有什么困难，避免仅换故事人物后重复整节活动。
- 学期末可以安排回顾与过渡准备，不默认要开展考试压力教育；主题由现实需要决定。

## 教案与课件同步

逐项核对情境、目标、指令、学生任务、材料、观察证据与教师备注的适配是否一致。不能出现教案标注一年级上学期，PPT却要求独立阅读长句、填写抽象三栏分析或强制公开分享。

学生画面用生活语言；来源概念、设计依据及不确定性放在教师材料和备注。年龄、学期和单次表现均不用于诊断或能力分流。

## 考试主题与实际安排

- 用户已说明学校或班级有考试时，保留考试、备考或考前焦虑主题，围绕实际考试情境设计；不能仅因学生是一、二年级就改为作品展示、学习回顾或其他主题。本项目用户已明确说明小学一、二年级仍有考试，后续相关请求按其提供的实际情境处理，不把这项说明扩大为所有学校的统一事实。
- 纸笔、口头、操作等形式，以及科目、时长、用品和求助边界，以用户或学校提供的信息为准。未说明时可标注“考试形式及规则按学校实际安排，尚未提供”，继续完成不依赖该信息的设计；仅在会实质改变核心活动时澄清。不从“有考试”推断纸笔考试，也不自动认定为非纸笔评价。
- 区分规范要求、用户描述的实际安排和教学设计假设。涉及现行规定判断时按需核验并在教师说明中简短交代，不把规范要求当成对实际情况的断言，也不据此擅自替换用户主题。
- 低年级考试主题可具体练习用品准备、理解要求、分步作答或完成任务、规则允许的求助、紧张时的支持和考后反馈。任务随真实考试形式与学生理解调整，不公开排名、不以恐惧或羞辱动员，也不借主题班会额外组织考试。

## 有来源的边界

- 教育部《关于大力推进幼儿园与小学科学衔接的指导意见》明确将小学一年级上学期设置为入学适应期，并强调尊重原有经验与发展差异、游戏化和体验式学习。这支持上学期优先关注适应，但不证明上述所有活动差异均有直接实证，也不意味着下学期无需适应支持。[官方原文](https://hudong.moe.gov.cn/srcsite/A06/s3327/202104/t20210408_525137.html)
- 中国大陆适用的2025年《关于进一步加强中小学日常考试管理的通知》明确小学一二年级不进行纸笔考试。这是规范要求，不足以断言每所学校实际没有考试；“不进行纸笔考试”也不能改写成“不存在任何形式的考试或评价”。用户说明实际有考试时，按上节保留主题、区分信息来源，不将学校实际安排表述为政策许可。[官方原文](https://hudong.moe.gov.cn/srcsite/A06/s3321/202512/t20251216_1423634.html)

上述官方页面于2026年10月26日核验。今后涉及现行规定或地方安排时，按需重新核对；不把发布日期当作课堂效果证据。
