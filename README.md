# 知心教研工作台

心理学知识蒸馏与主题班会教案工作台。项目将逐步从原有 AI 面试平台迁移为教育工作者使用的资料整理、知识提炼和班会教案设计工具。

## 核心功能

- **资料蒸馏**：针对有权使用的心理学书籍摘录、教师课程、讲义和个人笔记生成原创摘要、概念卡、实践方法与边界提醒。
- **主题班会教案**：根据主题、学段、时长和班级背景生成教案流程、教师引导语、学生任务、板书提纲和复盘建议。
- **教案 Skill**：`skills/theme-class-meeting-planner/SKILL.md` 描述了完整的教案生成流程、输出结构、质量检查和心理安全原则。

## 技术栈

- Next.js 16 / React 19
- TypeScript
- Tailwind CSS 4
- OpenAI SDK（兼容 DashScope / 百炼接口）

## 本地运行

```bash
npm install
cp .env.example .env.local
npm run dev
```

在 `.env.local` 中配置模型访问密钥：

```dotenv
DASHSCOPE_API_KEY=your_dashscope_api_key
BAILIAN_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
BAILIAN_MODEL=qwen-plus
```

未配置 API 密钥时，蒸馏和教案生成接口会返回明确的配置提示。请勿把真实密钥提交到 Git。

## 使用方式

1. 打开首页进入“心理学书籍与课程蒸馏”，填写资料来源、页码/时间戳和自己有权使用的文本片段。
2. 检查蒸馏结果中的概念、教学转化建议、边界和来源信息。
3. 进入“主题班会教案工坊”，输入班会主题、适用学段、时长和班级背景。
4. 将蒸馏结果作为可选资料输入，生成后由教师核对并根据实际班级情况修改。

## 资料、版权与学生安全

- 只上传自己有权处理的资料；不要将系统用于复制或替代整本书、整节付费课程。
- 模型输出需要教师核验。未提供的页码、课程时间戳、研究和引文不得当作事实。
- 不输入可识别学生身份的信息、诊断或不必要的家庭隐私。
- 班会活动应提供低风险参与方式，不强迫学生公开披露创伤或敏感经历。
- 本工具用于教育备课，不替代心理诊断、治疗或学校危机干预流程。
