# 主题班会教案工作台

把心理学书籍与教师课程中的知识，转化为可追溯、可复用、可落地的主题班会教案。

项目从原有的面试练习应用转型为两条核心工作流：

1. **资料蒸馏**：输入有权使用的读书笔记、课程笔记或转写片段，提炼核心概念、实践方法、课堂活动转化、来源依据与适用边界。
2. **教案生成**：选择已蒸馏的知识卡，结合年级、班级情境、主题和时长，生成教学目标、课堂流程、教师话术、讨论问题、效果评价、课后延伸与学生支持边界。
3. **Skill 工作流**：仓库内的 **skills/theme-class-meeting/SKILL.md** 规定知识蒸馏与主题班会设计方法，可供兼容 Skill 的 AI 编程或写作工具使用。

## 技术栈

- Next.js 16 / React 19 / TypeScript
- Tailwind CSS 4
- OpenAI SDK，兼容阿里云百炼 DashScope API
- Zod 请求与模型输出校验

## 本地启动

需要 Node.js 20.9 或更新版本。

    npm install
    cp .env.example .env.local

在 .env.local 中填写真实的 DASHSCOPE_API_KEY，然后运行：

    npm run dev

访问 http://localhost:3000。

生产构建：

    npm run build
    npm run start

## 环境变量

| 变量 | 用途 |
| --- | --- |
| DASHSCOPE_API_KEY | 百炼 API 密钥 |
| BAILIAN_BASE_URL | OpenAI 兼容接口地址 |
| BAILIAN_MODEL | 使用的模型名称，默认 qwen-plus |

不要把真实 API Key 写进代码或提交到 Git。

## 使用流程

### A. 蒸馏心理学书籍或教师课程

1. 在“蒸馏资料”中选择资料类型。
2. 填写书名/课程名、作者/授课教师和目标使用对象。
3. 粘贴你有权使用的读书笔记、课程笔记、允许使用的短摘录或转写片段。建议保留章节、页码或时间戳。
4. 审核概念、方法、课堂转化、来源定位与适用边界。
5. 保存到浏览器知识库，并导出 Markdown 备份。

### B. 生成主题班会教案

1. 填写主题、年级、时长和真实班级情境。
2. 选择要使用的知识卡，或补充教研组要求。
3. 生成并审核教案。
4. 导出完整 Markdown，按学校模板、学生特点和真实课时调整。

### C. 在 AI 工具中使用 Skill

将 **skills/theme-class-meeting/** 提供给支持 Skill 文件的工具，或直接使用其中的 **SKILL.md** 作为系统化工作指引。Skill 会要求模型明确学生需要、选择方法、设计可观察目标、编排活动、提供教师话术并进行安全检查。

## 数据与隐私说明

- 当前知识库保存在**当前浏览器的 localStorage**，不是云端数据库；清理浏览器数据可能导致内容丢失。
- “蒸馏资料”和“生成教案”请求会把表单内容发送到你配置的模型服务。不要粘贴学生姓名、可识别的个人信息、保密的个案记录或无权处理的材料。
- 不要将整本受版权保护的书籍或整门付费课程直接粘贴到模型。优先使用自己的笔记、合理范围内的摘录和结构化课程要点；输出应是转化后的摘要与教学方法，而不是原文替代品。
- 模型输出是教案初稿，不是心理诊断或专业心理治疗建议。涉及欺凌、创伤、自伤风险、家庭暴力或其他高风险议题时，应遵守学校制度并寻求合格专业人员支持。
- 重要知识卡请导出并备份到 **knowledge/books/** 或 **knowledge/courses/**。仓库不预置未经你提供与核实的书籍、老师课程内容。

## 当前边界与后续方向

首版已具备可操作的资料蒸馏、浏览器知识库、教案生成与 Markdown 导出流程。知识库尚未连接服务端数据库，也不会自动把浏览器中的知识卡提交到 GitHub。后续可根据实际材料增加批量导入、文件解析、云端知识库、来源检索、版本管理和学校教案模板。
