# 知心教研工作台

心理学知识蒸馏与主题班会教案工作台。把心理学书籍和教师课程整理成可追溯知识卡片，再自动组合为适龄、活动体验型的主题班会。

## 核心功能

- **资料蒸馏**：导入 PDF、TXT、Markdown，或粘贴有权使用的章节摘录、教师文章与课程文字稿。
- **知识库**：将蒸馏结果保存为知识卡片，保留资料类型、来源名称、作者/讲师、章节页码或位置。
- **教案自动匹配**：根据班会主题、学段和班级背景推荐相关知识卡片；可手动取消不相关来源。
- **体验式班会**：生成情境体验、小组合作、角色扮演、技能练习、课后行动、教师引导语和复盘方案。
- **教案 Skill**：`skills/theme-class-meeting-planner/SKILL.md` 定义教案工作流程与质量标准。

## 技术栈

- Next.js 16 / React 19 / TypeScript
- Tailwind CSS 4
- OpenAI SDK（兼容 DashScope / 百炼接口）
- PDF.js（在浏览器提取 PDF 文字层）

## 本地运行

```bash
npm install
cp .env.example .env.local
npm run dev
```

在 `.env.local` 中配置：

```dotenv
DASHSCOPE_API_KEY=your_dashscope_api_key
BAILIAN_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
BAILIAN_MODEL=qwen-plus
```

未配置模型密钥时，蒸馏和教案生成 API 会显示明确错误，不会伪造结果。

## 使用流程

1. 在“资料蒸馏”登记书名/文章名、作者或讲师、章节/页码或课程位置。
2. 上传 PDF/TXT/Markdown，或粘贴自己有权使用的章节摘录与课程文字稿。
3. 检查蒸馏内容并保存到知识库。
4. 在“主题班会教案工坊”输入主题、学段、时长与班级背景。
5. 检查自动推荐的知识卡片，可取消勾选，然后生成教案。
6. 复制或导出 Markdown 教案，教师核对后再用于实际课堂。

## 当前限制

- 知识库保存在当前浏览器的 localStorage 中，不是云端数据库，不会自动跨设备同步。
- PDF 解析只读取文字层；扫描图片 PDF 需要先做 OCR。EPUB 暂不直接解析，可先导出 PDF/TXT。
- 自动匹配目前基于关键词，不等同于向量语义检索，也不能替代教师对资料准确性与适龄性的审核。
- 生成结果没有自动保存为云端教案版本；导出 Markdown 后可自行归档。

## 资料版权与学生安全

- 只上传自己有权处理的资料；输出以原创总结为主，不复现整章书籍或完整课程。
- 不编造书籍作者、课程内容、页码、研究或引文；未提供来源位置时明确标记。
- 不输入可识别学生身份的信息或不必要的家庭隐私。
- 班会活动应提供低风险参与方式，不强迫学生公开披露创伤或敏感经历。
- 本工具用于教育备课，不替代心理诊断、治疗或学校危机干预流程。
